# K.D. Dilini — 3D Walkable Nature Portfolio

> Inspired by the award-winning 3D nature floating island portfolio design of **jordan-breton.com**, crafted with **Three.js**, **React**, **TypeScript**, and **Tailwind CSS**.

## ✨ What Makes This Unique

Instead of a generic 2D scrolling webpage, visitors directly control a character avatar and **walk through a 3D nature floating island in the sky**:

- **Walkable Avatar & Physics**: Explore the island freely using **W, A, S, D** or Arrow keys, with terrain elevation tracking and island edge bounds.
- **Dynamic 3rd-Person Orbit Camera**: Drag the mouse anywhere on screen to smoothly orbit and look around the 3D landscape.
- **Interactive Nature Landmarks**:
  - **Dilini's Hermitage & Monument**: Character profile, education at SLIIT, and background.
  - **Ancient Architecture Tree**: Inspect 14+ shipped projects (Edge-AI Smart Glasses, Enterprise Spring Boot, RabbitMQ, AuraLink, etc.).
  - **Cascade of Streaming APIs**: Animated waterfall and mist particles flowing into 30+ engineering skills.
  - **Monoliths of Accreditation**: Standing stone circle displaying 13 verified certificates and credentials.
  - **Campfire of Innovation**: Warm glowing embers featuring live GitHub repository telemetry and YouTube channels.
  - **Pavilion of Inquiries**: Direct inquiry submission form and one-click PDF CV download.
- **Fast-Travel Compass**: Instantly teleport across any landmark on the island.
- **Procedural Nature Audio**: Procedural grass footsteps, discovery chimes, and gentle wind ambience powered by the Web Audio API (zero audio files needed).
- **Vercel & GitHub Ready**: Pre-configured with `vercel.json` and Vite for instant 1-click cloud deployment.

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open browser at http://localhost:3000
```

## 🌐 Deploying to Vercel (1-Click)

1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of 3D Walkable Nature Portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/dilini-3d-nature-portfolio.git
   git push -u origin main
   ```

2. Go to **[vercel.com](https://vercel.com)**:
   - Click **Add New Project**
   - Import your GitHub repository
   - Framework Preset: **Vite**
   - Click **Deploy**!

Vercel will automatically build and deploy your 3D walkable portfolio with global edge CDN routing and HTTPS.
